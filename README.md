# BilCELL İş Planı Uygulaması

Bu projede PHP ve MySQL kullanarak basit bir iş planı uygulaması örneği yer alır. `installer.php` dosyası ile veritabanı ve tablo oluşturulur, ardından `index.php` üzerinden iş listesi yönetilebilir.

## Kurulum
1. `installer.php` dosyasını tarayıcıdan açın.
2. Veritabanı bilgilerinizi girerek kurulumu tamamlayın.
3. Kurulum sonrası oluşturulan `config.php` dosyası üzerinden bağlantı yapılır.

## Kullanım
- Yeni iş eklemek için formu doldurun.
- Eklenen işler AJAX ile sayfa yenilemeden listeye eklenir.

Bu proje örnek amaçlıdır ve geliştirmeye açıktır.
